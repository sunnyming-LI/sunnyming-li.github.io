Adaptive Querying

Questioning strategies for robot learning in household tasks

This research investigates how robots can ask questions to learn user preferences in household tasks. In a comparison of three strategies, parallel exploration was favored for perceived intelligence and efficiency and involved greater cognitive load. Adapting the strategy to the user and situation remains a future direction.

Questioning Pattern

System Implementation

Framework Design & User Study

System Architecture

Scene Understanding extracts objects from the environment and task. The Ask Module applies the strategy, Object Grounder and Preference Parser resolve references and preferences, and Ambiguity Evaluator determines when information is sufficient. The Act Module then executes atomic actions.

Additional system architecture views (1)

Experiment Setting

Eighteen participants compare three tidying scenarios: bar counter, study desk, and office desk. Each layout contains approximately 10–12 items and 2–3 storage spaces.

Experiment

Every strategy is compared in each task scenario using interaction logs, workload, curiosity, self-efficacy, and qualitative feedback.

Conclusion

Parallel Exploration was favored for perceived intelligence and efficiency, with greater cognitive load. Direct Querying was experienced as repetitive; User-Preference-First as accurate but slower.

Implications & Future Directions

The framework supports reproducible comparison of questioning strategies. A future adaptive robot could switch strategies according to user and context to support longer-term collaboration.
